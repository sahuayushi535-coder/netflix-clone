# netflix-clone
A responsive Netflix-inspired landing page built using HTML and CSS.

# Features
- Netflix-inspired hero section with background image
- Responsive navigation bar
- Netflix logo and sign-in button
- Language selection button
- Email input with "Get Started" button
- Trending Now section with movie cards
- Movie ranking numbers
- "More Reasons to Join" section
- Interactive FAQ section
- Responsive footer with navigation links
- Mobile-responsive design
- Hover effects and smooth transitions

# Technologies Used
- HTML5
- CSS3
- Google Fonts – Inter

# How to Run
1. Clone this repository:
git clone https://github.com/your-username/netflix-clone.git
2. Open the project folder.
3. Open index.html in your browser.
